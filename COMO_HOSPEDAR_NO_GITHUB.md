# 🌐 Guia Passo a Passo: Como Hospedar o REDE VIVA 360 Gratuitamente no GitHub Pages

O **GitHub Pages** é o serviço oficial e 100% gratuito do GitHub para colocar sites no ar com endereço próprio na internet (`https://seu-usuario.github.io/gestao-equipes-rdo/`). 

Com isso, o sistema funcionará online para qualquer eletricista, encarregado ou supervisor acessar pelo celular, tablet ou computador.

---

## ⚡ Método 1: Direto pelo Navegador (Sem Instalar Nada - 3 Minutos) ⭐ RECOMENDADO

Como sua pasta já está aberta no Windows Explorer, esse é o caminho mais rápido e simples.

### Passo 1: Criar o Repositório no GitHub
1. Acesse **[github.com](https://github.com)** e faça login na sua conta (se não tiver conta, crie uma gratuitamente em 1 minuto).
2. No canto superior direito, clique no botão **`+`** e selecione **"New repository"** (ou clique no botão verde **"New"**).
3. Preencha as opções:
   - **Repository name:** digite `gestao-equipes-rdo` (ou `redeviva-rdo`).
   - **Public:** deixe marcado como **Public** (Público é gratuito para hospedar no Pages).
   - **Importante:** Deixe **desmarcadas** as opções: *Add a README file*, *Add .gitignore* e *Choose a license*.
4. Clique no botão verde no final: **"Create repository"**.

---

### Passo 2: Enviar os Arquivos da sua Pasta
1. Na tela seguinte que o GitHub abrir, procure a frase:
   > *"or push an existing repository from the command line"* ou o link **"uploading an existing file"** (veja a palavra azul **uploading an existing file**). Clique nele.
2. Agora, vá na sua pasta do Windows Explorer que aparece na imagem:
   `C:\Users\udpl77554\.gemini\antigravity\scratch\gestao-equipes-rdo`
3. Selecione **todos os arquivos** da pasta:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `seed-data.js`
   - `manifest.json`
   - `sw.js`
   - `icon.svg`
   - `README.md`
   - `COMO_PUBLICAR_GOOGLE_PLAY.md`
4. **Arraste todos esses arquivos juntos** e solte dentro do retângulo do GitHub onde diz *"Drag files here to add them to your repository"*.
5. Aguarde as barrinhas de upload completarem (demora cerca de 10 a 20 segundos).
6. No final da página, no campo *"Commit changes"*, clique no botão verde **"Commit changes"**.

---

### Passo 3: Ativar o Site no Ar (GitHub Pages)
1. No menu superior do seu repositório no GitHub, clique na aba **⚙️ Settings** (Configurações).
2. Na barra lateral esquerda, desça até a opção **Pages** (com ícone de documento).
3. Na seção **Build and deployment > Branch**:
   - Onde está escrito **`None`**, clique e mude para **`main`** (ou `master`).
   - Ao lado, deixe a pasta como **`/(root)`**.
   - Clique no botão **"Save"**.
4. Aguarde de 1 a 2 minutos e recarregue a página (pressione F5).
5. No topo da página de configurações aparecerá uma faixa verde:
   > **"Your site is live at https://seu-usuario.github.io/gestao-equipes-rdo/"**

🎉 **Pronto! Seu sistema está no ar na internet!**

## 📱 Dica de Ouro para Celular (Instalar como App)
Assim que o link estiver no ar:
1. Abra o link gerado no navegador **Google Chrome** do seu celular Android.
2. Toque nos **três pontinhos (⋮)** no topo do Chrome.
3. Toque em **"Instalar aplicativo"** ou **"Adicionar à tela inicial"**.
4. O ícone oficial do **REDE VIVA 360** ficará instalado como um app nativo no celular dos eletricistas, funcionando em tela cheia e com cache offline!

## 💻 Método 2: Usando o GitHub Desktop (Aplicativo Visual no Windows)

Se você preferir gerenciar o projeto por um aplicativo visual no Windows para atualizar arquivos no futuro com 1 clique:

1. Baixe e instale o **[GitHub Desktop](https://desktop.github.com/)**.
2. Abra o GitHub Desktop e faça login com sua conta do GitHub.
3. No menu superior, clique em **File > Add local repository...**
4. Clique em **Choose...** e selecione a pasta:
   `C:\Users\udpl77554\.gemini\antigravity\scratch\gestao-equipes-rdo`
5. Se aparecer a mensagem *"This directory does not appear to be a Git repository"*, clique no link azul **create a repository**.
6. Clique em **Publish repository** no topo.
7. Acesse o GitHub no navegador e ative o **Pages** em **Settings > Pages > Branch main > Save**.
